U1.1 / ESP32-S3

Bad Alarm Clock

An ESP32-based alarm clock with a real-time state machine, interrupt-driven encoder/button input, SPI OLED display, NTP-synced RTC, and live weather over REST. Built from breadboard to a soldered protoboard in a custom 3D-printed enclosure, with an MQTT hub demonstrating pub/sub IoT architecture.
